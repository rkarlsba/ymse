Note om multimetre

Der fås mange multimetre med serielt interface, både dyre og billige. Se beskrivelsen af hvert enkelt apparat.

Har man et multimeter med serielt interface, kan man opsamle data fra alle apparater med en analog udgang. Man måler blot spændingen fra den analoge udgang med multimetret og tilslutter multimetret til den serielle port.

I Datalyse kan man ved valg af måleparametre vælge en konverteringsfaktor. Denne faktor kan være gemt i filen vernier.ini. Brugeren kan selv redigere vernier.ini.

Eksempel

Trykmåleren PTM100 giver en analog spænding på 1mV pr mBar, og offset er 0 mBar. I vernier.ini tilføjer man så linien.

PTM100 trykmåler"P/Bar"1000.0"0.0

Formatet er:

Titel"Fysisk størrelse/enhed"konverteringsfaktor"offset
