Mettler Toledo MPxxx pH Meters

MP230 pH meter

Menu in Datalyse:

Graphical measurement

Baud rate 2400, even parity, 1 stop, 7 data bits.

No version command, but a measuring is made. The cable is standard.

Setup for communication with pc:

MP230 pH meter has no commands. The communication is one-way only but you can set the device to transmit data constantly. A data set is transmitted about every 1,5 seconds.

Press »R« until the symbol for data communication in the lower right corner of the display is lit.

Press »ÖA« until the symbol in the upper left corner is gone. Only Ö should be lit. Finally press Mode until the function you want, pH or mV, is displayed.

Now the device transmits data to the pc. Datalyse will clear the data buffer before each measurement and gather a new measurement. The time of measurement is the time the new measurement is received.

This is complicated but I could not find an easier way. Mettler Toledo should make a better interface that allows you to set up the device from the pc.

Ps:

A serial interface is not just a serial interface. Note the phrasing:

    RS232 data output, RS232 interface, RS232 two-way port…

Data output means that you cannot control the device from the pc!

MPC227 pH/Conductivity meter

Menu in Datalyse:

Multitable

Baud rate 2400, even parity, 1 stop, 7 data bits.

No version command, but a measuring is made. The cable is standard

Setup for communication with pc:

MPC227 pH/Conductivity meter has no commands. The communication is one-way only but you can set the device to transmit data constantly. A data set is transmitted about every 2,3 seconds.

You can measure either pH or conductivity or both. You have to setup each display independently.

Press »R« until the symbol for data communication in the lower right corner of the display is lit.

Press »ÖA« until the symbol in the upper left corner is gone. Only Ö can be lit. Finally press Mode until the function you want is displayed.

Now the device transmits data to the pc. Datalyse will clear the data buffer before each measurement and gather a new measurement. The time of measurement is the time the new measurement is received.

This is complicated but I could not find an easier way. Mettler Toledo should make a better interface that allows you to set up the device from the pc.

Ps:

A serial interface is not just a serial interface. Note the phrasing:

    RS232 data output, RS232 interface, RS232 two-way port...

Data output means that you cannot control the device from the pc!
