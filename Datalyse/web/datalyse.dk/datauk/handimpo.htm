    Menu in Datalyse

    Measure (t,f(t))
    Read log

    Wavelength region: 380 - 760 nm
    Intensity range: 0 - 300 kLx

    The sensor is calibrated from the factory and offset and factor are printed on the sensor.

    If you want to see the calibration values or type new values into the instrument you can do

    this by selecting Hold and then the Cal menu and then type in the calibration data.

    Manometer/Barometer version 1.00

    Menu in Datalyse

    Measure (t,f(t))
    Multitable, measuring on one or more inputs
    Multigraph, measuring on both inputs.
    Read log

    Baud rate 9600, no parity, 1 stop, 8 data bits. Version command: "V".

    Manometer/barometer can measure pressure using 2 different sensors:

    0-1300 hPa
    500-7000 hPa

    The instrument has an internal sensor as well.

    The sensors are calibrated from the factory and offset and factor are printed on the sensor. Before measuring with the external sensors the calibration values must be typed into the instrument. This is done by selecting Hold and then the Cal menu and then typing in the calibration data. The sensor in question must be connected to the instrument before you enter the Hold / Cal menu, so that the instrument what data is for which sensor.

    The instruments can save 2 sets of calibration data, one set for a 0-1300 sensor and one set for a 500-7000 sensor.

    Selecting the unit: mmHg, hPa or psi is done by pressing ON and up arrow simultaneously when the instrument is off. Select the unit by pressing up or down arrow, end by pressing Cal.

    Functions and operating overview

    HOLD, CAL, MODE, SET, AVG, MIN, MAX

    The functions and operations are identical for all instruments, but the display is of course different

    Select function with Up and Dn.

    Function Activate function Setup OK Cancel
    Display t1, t2, t1-t2   Up / Dn    
    CALibration
    		 Hold, Up, Hold
    		 Up / Dn
    Up / Dn    		 CAL of t1
    CAL of t2    		 OFF
    MODE LINK Hold, 2*Up, Hold Dn CAL OFF
    MODE REMOTE Hold, 2*Up, Hold Up CAL OFF
    SET automatic log Hold, 3*Up, Hold Up / Dn CAL OFF
    SET manual log Hold, 3*Up, Hold   CAL OFF
    Manual log Hold, Hold      
    AVG, display Hold, 3*Dn     OFF (end)
    MINimum, display Hold, 2*Dn Up / Dn CAL OFF (end)
    MAXimum, display Hold, Dn Up / Dn CAL OFF (end)
    MINimum, bar Hold, 2*Dn, Hold Up / Dn CAL OFF
    MAXimum, bar Hold, Dn, Hold Up / Dn CAL OFF

    The names refer to the front panel of the thermometer:

    CAL should be OK. Hold should be MENU.

    Cancel should be OFF or ESC. In the manual Hold is used for cancel, but OFF works the same way.
