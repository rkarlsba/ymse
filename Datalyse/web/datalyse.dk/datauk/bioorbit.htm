Setup parameters

Baud rate 9600, no parity, 1 stop, 8 data bits.

No command for version, but when you select the device in Datalyse the command H is send to the device. If you do not get a connection, try pressing START for at least 2 seconds until the display reads »pr.on« This can cause a few problems!

Not all commands works as they should:

The integration time T can be set from 0.1 to 100.0 seconds but the command L for list stored values does not list the integration time and once you have used the command L the connection is interrupted.

When BioOrbit is turned on the integration time is set to 1.0 second and the background to 0.000. So Datalyse does the same as well as storing integration time and background.

BioOrbit setup...

In this menu, you can set the:

integration time from 0.1 to 100.0 s and the background from 0.000 to 9999.

Integration time is transmitted to BioOrbit. Both values are saved internally in Datalyse and written to the table next to every measuring.

If you have selected two devices of which BioOrbit is one, this menu is available in »Menu for two devices«.
