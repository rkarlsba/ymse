Kern Balances

Menu in Datalyse

Graphical measurement

In the menu »Measure (t, f(t))« you can choose between:

  1. Fast weighing
  2. Stable weighing

In the first case, the balance will send the result immediately, and in the second case, the balance will not send any data until the result is stable.

Minimum time: 1 second / 5 seconds. The Kern balance is setup for communication with a pc from the factory. When the device is connected in Datalyse, a measuring is made. This way you can see whether the connection to the balance works.

Kern EW

Baud rate 1200, no parity, 2 stop, 8 data bits.
If you have problems with the connection from Datalyse to the balance then see the manual section 8.2.2 Parameters for the serial interface and set output condition at interface to 71.o.c.7 (default setup)
