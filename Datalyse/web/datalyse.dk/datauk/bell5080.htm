Bell 5080 Teslameter

Menu in Datalyse:

Graphical measurement

Baud rate 2400, no parity, 1 stop, 8 data bits.

The cable is standard and there is a command for version.

To be able to measure set the selector at »Measure«. Datalyse tests whether this has been done and sets the meter to autorange.

In the menu for graphical measurement you can choose between 6 settings:

AC, Gauss
AC, Tesla
AC, AM
DC, Gauss
DC, Tesla
DC, AM

The meter can measure from 0 to +/- 3Tesla(30 kG) and from 0-20kHz.
