    Ultrospec 3000 spectrophotometer

    Menu in Datalyse:

    Measurements at one wavelength
    Spectrum, wavelength scan

    You can also use the terminal program in Datalyse with the spectrophotometer, but not for scanning since the data is send packed. See PS. below!

    Ultrospec 3000 uses a crossed cable, see Digital Meter

    Baud rate 19200, no parity, 1 stop, 8 data bits. Command "id" for version.

    When the spectrophotometer is controlled from the pc the display of the pc reads: remote control. The pc takes control by sending the command: control to the device and releases it again by sending release.

    At wavelength measuring you can measure absorbance and transmittance. At wavelength scan you can only measure absorbance.

    Reference measuring:

    At wavelength scan the scan is send as a packet to the pc. About 10 seconds later it is displayed on screen and in column A and B. Then you can copy column B to for instance column C using a column operation. At the next measuring the table is not erased, but new data will be written to column A and B when the scan has been completed.

    Thus a wavelength scan is done in two rounds:

    First measure on an empty glass and copy column B to column C. Then measure on the solution.

    When both measurings have been completed, column D is calculated as B - C. Then a graph is drawn of column D as a function of the wavelength.

    This is a bit troublesome but you can save the table of the reference, and start every experiment by loading a table, selecting the device and making a wavelength scan. This assumes nothing but that you measure at the same wavelengths as those saved in the table.

    Ultrospec 3000 does have a baseline, but you should follow the above procedure anyway.

    Other devices from Pharmacia: Ultrospec 1000, Ultrospec 2000 and Ultrospec 4000.

    Ultrospec 2000 has almost the same codes as Ultrospec 3000. So I assume that it is possible to use this device in Datalyse as well.

    PS. At a scan data is send packed, 3 bytes for each measuring. Pharmacia has not been able to give me information on the data format, so I cannot guarantee that the interpretation is correct!

    It should be noted that the spectrophotometer has functions not available through serial communication. Pharmacia Biosystems in Denmark actually admits that they prefer selling their own software to support the development of other software.

    Ultrospec II spectrophotometer

    Menu in Datalyse:

    Measure at one wavelength
    Spectrum, wavelength scan

    You can also use the terminal program in Datalyse with the spectrophotometer.

    The LBK Ultrospec II Spectrophotometer is connected to the pc with an ordinary serial cable. (same type as for the IMPO devices)

    Baud rate 600 (9600), no parity, 1 stop, 8 data bits. No version command.

    9600 in brackets means that the setting is changed by Datalyse when the device is selected.

    The command »STATUS« makes the spectrophotometer send data to the pc. For that reason this command is used in Datalyse to test the connection.

    Reference measuring:

    At wavelength scan the results are displayed on screen as they are being measured. When the scan is over, datalyse copies the measurings to column A and B in the table. Then you can copy column B to for instance column C using a column operation. At the next measuring the table is not erased, but new data will be written to column A and B when the scan has been completed.

    Thus a wavelength scan is done in two rounds:

    First measure on an empty glass and copy column B to column C. Then measure on the solution.

    When both measurings have been completed, column D is calculated as B - C. Then a graph is drawn of column D as a function of the wavelength.

    This is a bit troublesome but you can save the table of the reference, and start every experiment by loading a table, selecting the device and making a wavelength scan. This assumes nothing but that you measure at the same wavelengths as those saved in the table.

    LBK Ultrospec II is from 1986, so it is an »old« device.
