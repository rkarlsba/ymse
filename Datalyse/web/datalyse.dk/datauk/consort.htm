Consort P601

Consort C831 multi-parameter analyser

Menu in Datalyse

Graphical measurement

Datalyse uses the command "8" and Consort responds with:

# VALUE UNIT °C CH Hour Date
nnnn 6.28 pH 21.2 1 17:09:41 13/01/2003

The first time a header is transmitted as well. The unit can be pH, mV or S/cm.

The log is not implemented in Datalyse. The log is not intended for data gathering but for printing.

Baud rate 2400, no parity, 1 stop, 8 data bits. Note that the cable is female in both ends!

Consort P601 pH-meter with Datalog, version 3.0

 Menu in Datalyse:

Graphical measurement, measures pH or temperature.
Multitable, measures pH and temperature.
The log is read, first set consort to display pH.

Note that the cable is female in both ends!! and it is crossed, see Digital meter.

Datalyse uses the command "8" and Consort responds with:

nnnn 6.28 ph 21.2

The first time a header is transmitted as well, which means you might lose the first measuring.

You can test the communication in the menu topic »Terminal« is necessary.

The log can contain 100 measurings, the setting is 100% troublesome as it was not intended for data gathering but for printing.

Baud rate 2400, no parity, 1 stop, 8 data bits.
