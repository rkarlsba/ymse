Genesys 6

Measure at one wavelength
Spectrum, wavelength scan
Baseline, wavelength scan
Zero value

You can also use the terminal program in Datalyse with the spectrophotometer.

Genesys 6 is connected to the pc with an ordinary serial cable, the cable must be 9 pin female at the device end though. You can buy a converter if necessary.

Baud rate 19200, no parity, 1 stop, 8 data bits.

Command MODEL for model and REV for software version.

The command »SAMPLE« makes the spectrophotometer send the absorbance to the pc.

Wavelength interval: 190 nm - 1100 nm

It is possible to measure absorbance, transmittance and concentration. Spectral bandwidth 1.8 nm.

Genesys 8 

Menu in Datalyse

Spectrum, wavelength scan
Baseline, wavelength scan
Zero value
Release control

Spectronic 8 Genesys is connected to the pc with zero-modem cable, the cable must be 9 pin mail- female. Baud rate 9600, no parity, 1 stop, 8 data bits.

Genesys 8 can scan a spectrum when you use it off-line. For each scan you choose the first wavelength and the last wavelength. A scan consists of two processes, 1 measuring the base line and 2 the actual scan. It is a little cumbersome and slow.

Unfortunately the Genesys 8 does not have a command for scan. Hence Datalyse performs a scan by first measuring the base line. This scan is placed in column C in the table. At any following scan the base line is automatically subtracted. This method does however require that you measure at the same wavelengths as you did when measuring the base line. Genesys scans slowly this way. Choose large steps, e.g. 10 nm.

This method is not as good as a real scan and you might as well be using the cheaper device Genesys 20.

You can also use the terminal program in Datalyse with the spectrophotometer.

Genesys 10 is connected to the pc with an ordinary serial cable, the cable must be 9 pin female at the device end though. You can buy a converter if necessary.

Baud rate 19200, no parity, 1 stop, 8 data bits.

Command MODEL for model and REV for software version.

The command »SAMPLE« makes the spectrophotometer send the absorbance to the pc.

Wavelength interval:

Model UV: 190 nm - 1100 nm
Model VIS: 325 nm - 1100 nm

It is possible to measure absorbance, transmittance and concentration. Spectral bandwidth 5 nm.

Spectrum and baseline:

Genesys 10 does not have a command for scan. Hence Datalyse performs a scan by first measuring the base line. This scan is placed in column C in the table. At any following scan the base line is automatically subtracted. This method does however require that you measure at the same wavelengths as you did when measuring the base line.

Scanning might be problematic, since the spectrophotometer often get out of range. If you experience problems, try reducing the wavelength interval to for instance [400 nm; 800 nm] and remember that an ordinary cuvette does absorb light in the UV-area.

Spectronic 301 is connected to the pc with an ordinary serial cable, the cable must be 9 pin female at the device end though. You can buy a converter if necessary.

Baud rate 1200, no parity, 1 stop, 8 data bits. No version command.

The command »SND« makes the spectrophotometer send the absorbance to the pc. Datalyse uses this to test the connection to the device.

Spectrum and baseline:

Spectronic 301 does not have a command for scan. Hence Datalyse performs a scan by first measuring the base line. This scan is placed in column C in the table. At any following scan the base line is automatically subtracted. This method does however require that you measure at the same wavelengths as you did when measuring the base line. Spectronic 301 scans slowly this way. Choose large steps, e.g. 10 nm.

Spectronic 301 is from 1992, so it is an »old« device. Contact Rungsted Gymnasium for additional information on the spectrophotometer. It is not dealt anymore!
