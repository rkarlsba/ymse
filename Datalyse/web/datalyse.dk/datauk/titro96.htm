TitroLine 96 titration unit and Titronic Basic

TitroLine 96

Menu in Datalyse
Graphical measurement
Start titration
Stop titration
Read data

Baud rate 4800, no parity, 2 stop bits, 7 data bits. Command RH for identification. Pin configuration of the RS 232 socket (4-channel mini DIN):

pin 1: TxD
pin 2: RxD
pin 3: Gnd
pin 4: not used

Graphical measurement

Upon each measuring the pH is read and V/mL is dosed and the measuring is paused until the time pr measurement has elapsed. When the burette is empty, it is automatically refilled. Note that the smallest possible measuring time is 1 second. The graph is copied to the table after the measurements has ended.

Start titration

The setup of the Titroline 96 is used. Choose set up before hand. The values of (Vol/mL, pH, t/s) are saved in the titration unit.

Stop titration

The titration is stopped and the sample identification is written to the memo in Datalyse.

Read data

The saved values are transmitted to the table in Datalyse.

Titronic Basic

Menu in Datalyse
Graphical measurement

Baud rate 4800, even parity, 2 stop, 7 data bits.

If you use 2 devices in Datalyse, Titronic Basic can be one of them. Then you can choose between different types of measuring:

Table
(t,y1, y2)-graph
(x,y)-graph

If you choose the (x, y)-graph, you would probably prefer to have Titronic Basic connected to the »lowest« comport, as the graph is most likely to have V/mL on the x-axis and for instance absorbance on the y-axis.

Using two devices you have two options:

1: no dose
2: 0.05 mL dose
