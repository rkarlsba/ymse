The TES-1336 Light Meter is capable of measuring illuminance in lux or foot-candles. Measuring intervals: 20, 200, 2000 or 20000 lux/Fc.

The TES-1553 Sound Level Meter is capable of measuring sound in the interval from 30 dB to 130 dB. Precision: 1.5 dB

It has a serial interface and it has an analog ac and dc output. If you use the analog ac output the device can function as a microphone, i.e. you can use it for Fourier analysis.

You can use the dc output in connection with a fast data logger to measure reverberation times.

Baud rate 9600, no parity, 1 stop, 8 data bits. Cable is included but you can use a standard cable.

The TES-1561 Hygrometer is capable of measuring relative humidity and temperature. Measuring intervals: 10% - 95 % RH and -20 °C to 60 °C.

The TES-1380 pH Meter is capable of measuring pH and temperature. Measuring intervals: 0-14 pH, 0-1999mV and 0 °C-100 °C.

Accuracy: 0.01 pH (resolution 0.001 pH) and 0.1 °C.

One-point calibration at pH 7 or two-point calibration at pH 7, pH 4.

Baud rate 9600, no parity, 1 stop, 8 data bits. Cable is included but you can use a standard cable.

Control panel: setup data and time and read log

Date and time:

Here you select time per measurement, date and, if necessary, ID. Write the value and

press »Send Id« or »Send time« or »Send date«.

When you select »Control panel« Datalyse will test if the device is logging. If it is, you cannot set the time per measurement etc., but you can still read the log.

Read log:

First click on »Read state«. When the state has been read you can select a record and read it by clicking »Read record«. When the full record has been transferred, the menu is closed and the record is displayed in the table in Datalyse.

Reading several records simultaneously:

You can select several records if they only contain one measurement each and the device is the TES-1336 Light Meter or the TES-1361 Hygrometer. Datalyse converts the time stamp to a current time and displays the measurements in the table. As you can see in the summary table below, the Sound Level Meter cannot log single values and the pH-meter saves single values independently of the records so you have to read them independently as well.

TES-1336 Light Meter

Press REC to log a single value, press and hold REC down for about 3 seconds to log a record of values or use the corresponding commands in the menu in Datalyse.

TES-1353 Sound Level Meter

First set the time per measurement and total logging time and then start the measuring record by pressing RECORD and pressing START.

If the TES-1353 Sound Level Meter is logging, communication with the device is turned off. The device will display the time passed since logging was started but you cannot tell when it will be completed. You cannot interrupt logging either. Keep a note of the total logging time.

TES-1361 Hygrometer

See Light Meter.

TES-1380 pH-meter

Press MEM to log a single value and press and hold MEM for about 3 seconds to log a record of values. There is no command to start logging a record of values from the pc. You can only log single values from the pc.

The device saves single values and multi records individually. Single values and multi records are also read independently.
