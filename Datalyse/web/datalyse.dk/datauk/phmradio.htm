    CDM210 conductivity meter

    Menu in Datalyse:

    Graphical measurement of conductivity or resistivity.
    Multitable, conductivity/resistivity, temperature
    Terminal program

    In Datalyse the meter is setup to measure conductivity or resistivity:

    1. conductivity S/m
    2. conductivity S/cm
    3. resistivity ohm.m
    4. resistivity ohm.cm

    Command "?TY" for version.

    If you cannot get a connection to the device, the reason might be that:

    1. The command ">CE" has not been send. This command enables remote control.
    2. Wrong data transfer.

    pHM92 pH meter

    Menu in Datalyse

    Graphical measurement of pH

    When measuring the device must display pH in mV or pH. Datalyse detects the unit automatically, but changing it while data gathering would make a mess of the data!

    No version command, but a measuring is made.

    If you cannot get a connection to the device, see data transfer.

    pHM93 pH meter

    Menu in Datalyse:

    Graphical measurement of pH
    Multitabel, of pH and temperature
    Terminal program

    When measuring the device must display pH in mV or pH. Datalyse detects the unit automatically, but changing it while data gathering would make a mess of the data!

    No version command, but a measuring is made.

    If you cannot get a connection to the device, the reason might be that:

    1. Wrong data transfer.
    2. The printout format should be <Result> not All. The device sends 7 lines of text to the pc. The measuring itself is in this text. If the settings is wrong, Datalyse will not be able to find the result.
    3. You have pressed GLP! This means that device sends a description of settings along with every measuring, which again means that datalyse will not be able to find the result!

    The strength of the device:

    The device is capable of measuring pH with 3 decimals.

    The weaknesses of the devices:

    You can setup the device on the front panel using the buttons. It is too much effort to make a similar setup from the pc.

    The device does not send an end character, e.g. eof. This is a problem, when several lines of text are send per measuring.

    Data transfer

    Baud rate 9600, no parity, 1 stop, 8 data bits. The cable is female in both ends and the conductors are crossed. You can use a standard null-modem cable.

    2 to 3 and 3 to 2 (data)
    8 to 4 and 4 to 8 (control), if the connector is 9 pinned.
    or
    5 to 20 and 20 to 5 (control), if the connector is 25 pin.
